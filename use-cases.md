# Aiola use cases

Ways coding agents use project context in Aiola. Browse the [live use-case hub](https://aiola.app/use-cases).

- [One app for coding agents, analytics and errors](https://aiola.app/use-cases/one-app-instead-of-many): Coding agents get errors, customer reports and project tasks directly in Aiola. Skip copying context across separate tools for each product you build and run.
- [Claude, Codex and Cursor subscriptions in one app](https://aiola.app/use-cases/multiple-ai-providers): Give coding agents the same task and project context across six providers. Skip repeated setup while comparing their work in the same Aiola workspace.
- [Website analytics and revenue beside your code](https://aiola.app/use-cases/analytics-in-one-place): Coding agents read traffic, revenue and search reports in one Aiola workspace. Skip chart exports when asking why your website numbers changed over time.
- [Turn a production error into a fix](https://aiola.app/use-cases/fix-production-errors): Coding agents get production errors and stack traces through Fix It in Aiola. Skip copying failure details into a separate chat before reviewing a fix.
- [Turn in-app user feedback into shipped fixes](https://aiola.app/use-cases/user-feedback-to-fixes): Coding agents get customer bug reports and feature requests directly in Aiola. Skip retyping feedback details when turning a customer report into a fix.
- [What happens after a coding agent opens a pull request](https://aiola.app/use-cases/github-issues-and-prs): Verify an agent pull request in Aiola with checks, changed files and a review agent. Link the task, use Human Review and merge after checking the diff.
- [Schedule coding agent jobs on your desktop](https://aiola.app/use-cases/scheduled-agent-jobs): Coding agents get saved project tasks and linked reports on a schedule in Aiola. Skip repeated prompts while your desktop stays on and awake for each run.
- [Give coding agents your plans, notes and todos](https://aiola.app/use-cases/plan-notes-todos): Coding agents get your open project note in Aiola Notebook side chat. Skip pasting plans while keeping searchable notes and todos beside each project.
- [Run several side projects as an indie hacker](https://aiola.app/use-cases/indie-hackers): Coding agents get production errors and customer reports for each side project in Aiola. Skip copying context when switching between the products you run.
- [Keep agency client work in separate workspaces](https://aiola.app/use-cases/agencies): Coding agents get client reports and project instructions in Aiola. Skip copying briefs while reviewing customer work across separate projects.
- [Run a solo SaaS product with coding agents](https://aiola.app/use-cases/saas-founders): Coding agents get customer reports, production errors and revenue numbers in Aiola. Skip copying context when deciding your SaaS product’s next fix.
- [Run parallel coding agents in separate worktrees](https://aiola.app/use-cases/parallel-coding-agents): Run coding agents in isolated Git worktrees with separate tasks in Aiola. Keep one view of running agents on your desktop, then review each diff and checks.
- [Triage support tickets and bug reports with agents](https://aiola.app/use-cases/support-tickets-to-fixes): Coding agents get customer reports and matching production errors in one Aiola task. Skip copying ticket details before reviewing an agent's proposed fix.
- [Track AI crawlers and assistant referrals](https://aiola.app/use-cases/ai-search-visibility): Coding agents get search indexing issues and affected website pages in Aiola. Skip exporting reports while tracking AI crawlers and search traffic.
- [Manage several businesses in one desktop app](https://aiola.app/use-cases/multiple-businesses): Coding agents get each business’s customer reports and tasks in Aiola. Skip copying context while reviewing revenue and work across projects.
- [Maintain open source projects with coding agents](https://aiola.app/use-cases/open-source-maintainers): Coding agents get GitHub issues and maintenance tasks directly in Aiola. Skip copying issue details while reviewing proposed project changes.
- [Run coding agents from your phone or tablet](https://aiola.app/use-cases/mobile-monitoring): Coding agents get tasks and approvals from your phone or tablet in Aiola. Skip returning to your desk to review changes; keep your desktop on and awake.
- [Grow search traffic with keywords and agent fixes](https://aiola.app/use-cases/seo-and-search-traffic): See Google and Bing search keywords beside traffic and AI crawler visits. A coding agent in the same app fixes the pages search engines struggle with.
- [Online stores: revenue, checkout errors and fixes](https://aiola.app/use-cases/online-stores): Run an online store with Stripe revenue beside visitors and funnels. A coding agent reads the checkout error or customer report and fixes the page.
- [Coding agents for non-technical founders](https://aiola.app/use-cases/non-technical-founders): Build with AI agents without reading code all day. Aiola shows what broke, what customers said and the numbers, then hands each one to a coding agent.
- [Product data in ChatGPT, Claude and Cursor](https://aiola.app/use-cases/product-data-in-chatgpt-and-claude): Ask ChatGPT, Claude or Cursor about your traffic, revenue, search keywords, errors and feedback. One OAuth connection covers every project in Aiola.
- [Mobile app errors and feedback your agents can fix](https://aiola.app/use-cases/mobile-app-developers): Send errors and user reports from your Swift, Kotlin or React Native app over HTTP. A coding agent reads each one in Aiola and proposes the fix.
- [Decide what to build next, then hand it to an agent](https://aiola.app/use-cases/product-managers): Compare feature requests, bug reports, errors and usage in one app. Turn the item you choose into a task with its own coding agent and a pull request.
- [Custom coding agents with skills and MCP tools](https://aiola.app/use-cases/custom-agents-skills-and-mcp): Save coding agents with instructions, memory and skills, and give each workspace its own MCP servers. Every repeat job starts with the right tools.
- [Launch day: live traffic, errors and fast fixes](https://aiola.app/use-cases/launch-day): Watch live visitors on launch day, catch new errors and read the first user reports. Hand each problem to a coding agent and review the fix that hour.
